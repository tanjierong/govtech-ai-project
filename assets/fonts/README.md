# Product School web fonts

Licensed web cuts of **Saans** (Displaay) and **Antarctican Mono** (Dunwich / I Love Typography).

`ps-fonts.css` is the public stylesheet. Course pages, the library, and the instructor hub load it so standalone HTML and the learning-platform mirror keep the same faces.

Do not commit desktop OTF/TTF packages, invoices, or extra italic/variable files here. Add a weight only when a page needs it.
