# Scenario B: ICA passport applications and renewals

## The situation

ICA processes a large volume of passport applications and renewals through an online channel run by a vendor. The vendor is withdrawing on a fixed date that will not move, and walk-in counters cannot cover today's online demand. Officers return many submissions for errors or missing documents, and each return adds days. Few applicants read the guidance before they apply.

## What the team found

- Most returns could have been avoided before submission.
- Applicants did not know what a complete application looked like for their situation.
- Parents renewing for a child were the most confused group.

## Constraints

- Applications contain identity documents and sensitive personal data.
- Final decisions stay with ICA officers.
- Whatever replaces the channel must be clear about what officers decide and what the system only suggests.
- It must stay accurate as rules change.

## Data rule

Make up every applicant, application and document you use. Never paste a real application, identity document or personal details.
